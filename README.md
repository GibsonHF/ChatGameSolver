# FadeCloud Chat Games Solver (Proof of Concept)

This project demonstrates a proof-of-concept solution for automating chat games on the FadeCloud Network (Minecraft 1.21.1).

> **Warning:** This tool violates the rules of the FadeCloud Network. Usage of this software may result in punishment. It is provided solely for educational purposes and as a demonstration of coding principles. **Use at your own risk.**

## Features

- **Auto Number Guessing:**  
  Automatically solves "Guess the Number" games by:
  - Randomly queuing guesses within the specified range.
  - Considering other players' guesses to avoid duplication.
  - Ensuring the fastest possible solution.

- **Math Equations Solver:**  
  Automatically calculates answers to math-based games for quick responses.

- **Auto Typing:**  
  Handles "type the word" games by inputting the correct answer with minimal delay.

- **Configurable Delay:**  
  The delay between actions can be customized directly in the code.

## Disclaimer

This tool is a **Proof of Concept** and should not be used in real environments where it may breach rules or guidelines. Its purpose is to showcase automation techniques and should be approached as a learning resource.
